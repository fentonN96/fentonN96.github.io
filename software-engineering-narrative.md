# Software Design & Engineering Enhancement Narrative

**Artifact:** Python CRUD Module

**Course:** CS 340: Client/Server Development

## Artifact Overview
[For artifact one in my software design and engineering enhancement, I was working on the Python CRUD module that was a project in my previous class CS 340: Client/Server Development. The purpose of this project was to make it perform a CRUD (Create, read, update, delete) operations that worked with a MongoDB database. I realized this original version was developed in Codio’s sandbox environment, and I had to switch from a preconfigured sandbox to a real database (MongoDB). The original artifact had shown some basic CRUD functions but was missing modularity, logging, validation, secure coding, and real-world database setup. I have selected this for my enhancement in the capstone so that I can demonstrate my foundation on backend skills: having a database connected to an application and then being able to perform structured operations on stored data. ]

## Enhancements and Course Outcomes
After reviewing the areas that needed a fix-up, I started to go through each enhancement and reasoned why the changes were specific for the operation to be better.

## Challenges and Learning
Some of the biggest learning moments came from the problems I ran into while setting up MongoDB locally, working with authentication, and getting my environment variables to load correctly.
